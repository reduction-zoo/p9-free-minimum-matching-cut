# Prepare evidence

Prepared 2026-09-26. The source is connected induced-`3P3`-free Minimum Matching Cut with threshold `k`; the target is connected induced-`P9`-free Minimum Matching Cut with the same threshold input format. The corpus contains 114 distinct source instances: 14 hand edge cases and 100 seeded random cases. Sizes range from 1 to 9 vertices, with 53 YES and 61 NO cases. `generate_cases.py` holds the hand examples and seed mapping. The corpus was fixed before any candidate reduction was constructed.

Run `uv sync --locked`, then `uv run --locked python campaigns/p9-free-minimum-matching-cut/work/check.py --self-test`. The command first runs `research/validate_preparation.py`, regenerates every random case from its stored seed, recomputes each answer, validates witnesses directly, and compares the Z3 answers with exhaustive partitions. It passed: 114 source cases and 116 separate target thresholds. `test_oracle.py` includes hand cases, bad cuts, a threshold-zero case, and a legal source `P9` that violates the target promise. An intentionally incorrect candidate returning a `K2` target and always extracting `NO-SOLUTION` was rejected on the positive `K2` source case.

Oracle: `z3-solver` 4.16.0.0, locked in `uv.lock`. One Boolean per vertex gives a partition. A crossing edge is the XOR of its endpoint Booleans; the solver enforces a nontrivial partition, crossing count in `[1,k]`, and crossing degree at most one for every vertex. Thus any satisfying assignment is exactly a feasible threshold matching cut, and conversely every such cut satisfies all constraints. Only `unsat` yields `NO-SOLUTION`; `unknown` raises an error. The returned partition is checked again by a direct graph predicate. Promise checks enumerate induced `3P3` or induced `P9`; all tested graphs are small. Exhaustive bipartitions provide an independent crosscheck for the fixed finite domain.

Coverage is finite: source graphs up to 9 vertices and target crosschecks up to 8 vertices, plus a hand P9 promise rejection. The candidate gate checks at most three target outputs per instance, so it does not establish the universal recovery claim. No construction, proof or solution has been claimed.
